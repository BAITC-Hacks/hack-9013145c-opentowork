## 60 секунд на вход в проект

Это **домен-агностичная AI-платформа**. Вся инфраструктура готова и проверена
запуском. Завтра к ней прикручивается домен Задачи — меняется малая часть файлов,
остальное не трогается.

```
Браузер :3000 ──> nginx ──┬──> статика React
                          └──> /api ──> FastAPI :8000 ──> PostgreSQL + pgvector
                                            │                  Redis
                                            │                  MinIO
                                            └──> очередь ──> Worker × 2
```

Ключевая идея, ради которой всё построено: **один и тот же вопрос не должен
дважды доходить до языковой модели**. Поэтому перед моделью стоят два кэша,
а после модели — четыре слоя проверки её ответа.

## Пять команд, которых хватит на весь день

```bash
docker compose up -d                        # поднять всё
docker compose logs -f api worker           # смотреть, что происходит
python scripts/smoke_test.py                # проверить, что ничего не сломали
docker compose restart api worker           # после правки кода
docker compose down -v && docker compose up -d   # «чистая машина» перед сдачей
```

На Windows `make` нет — используйте `docker compose` напрямую,
а тесты через `make test-docker` (или скопируйте команду из `Makefile`).

## Где точка входа в код

| Слой | Файл |
|---|---|
| HTTP-запрос приходит сюда | `app/main.py` → `app/api/v1/router.py` |
| Любая AI-операция проходит здесь | `app/ai/orchestrator.py` |
| Домен подставляется сюда | `app/domain/rules.py`, `app/models.py` |
| Экраны | `frontend/src/App.tsx` |

## Правила, которые не обсуждаются

1. **Коммиты только после 13:00.** До старта всё лежит в рабочем дереве.
2. **Коммит каждый час** с осмысленным сообщением — иначе дисквалификация (п. 5.4.8).
3. **Коммитят все участники со своих аккаунтов**, а не капитан за всех (п. 5.4.7).
4. **В 17:00 — стоп новым фичам.** Дальше только README, проверка чистой машины,
   репетиция и видео-бэкап демо.
5. Перед каждым коммитом в часы 4–5 — `python scripts/smoke_test.py`.

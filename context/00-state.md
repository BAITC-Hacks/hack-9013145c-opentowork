### 1.1 История выбора кейса (выбрана задача Б)

**А. «Аким на 5 часов»** — AI-симулятор управления городом.
Фиксированный бюджет, 5 решений по направлениям (транспорт, озеленение,
соцінфраструктура, безопасность, горсервис), итоговый Astana Quality of Life Score

→ Детерминированный симулятор + AI-слой объяснения. **Score считает формула,
не модель** — иначе провал по критерию «изменение решений меняет Score».

**Б. «Agentic AI для прогнозирования выработки ВЭС»** — трек Энергетика (наш).
Почасовой прогноз на 24–48 ч, walk-forward по февралю 2026, данные с марта 2023.
Агент сам тянет погоду по координатам, считает, анализирует, пересчитывает.
→ Настоящая ML-задача. **Ключевое требование: архивные ПРОГНОЗЫ погоды,
а не факт.** Источник подтверждён: Open-Meteo Historical Forecast API
(архив прогнозов с 2022, ветер на 10 и 100 м, диапазон дат одним запросом).

## 4. Ловушки, про которые надо помнить на демо

Появились вместе с исправлениями безопасности. Не баги — осознанные решения,
но они меняют поведение по сравнению с исходным каркасом.

1. **Кэш изолирован по пользователю** (`SEMANTIC_CACHE_SCOPE=user`).
   Сценарий с попаданием в кэш показывать **в одной учётке**: с другого аккаунта
   будет живой ответ, а не кэш.
2. **Документы по умолчанию `private`.** Материалы кейса заливать с
   `"visibility": "public"`, иначе их увидит только загрузивший.
3. **Лимит 20 AI-запросов в минуту на пользователя** (`RATE_LIMIT_AI`).
   На репетиции не долбить кнопку; при необходимости поднять в `.env`.
4. **`SEED_ON_START=False` в коде по умолчанию.** В `.env` для compose включено —
   но если запускаете что-то мимо compose, демо-данных не будет.
5. **`APP_ENV=prod` требует настоящих секретов.** Приложение откажется стартовать
   с дефолтным `JWT_SECRET`. Это защита, а не поломка.
6. **Демо-учётка `demo@demo.kz` имеет роль `EXPERT`, не `ADMIN`.** Она может
   наполнять базу знаний, но не читает данные других пользователей.
7. **Ландшафт и модели — процедурная 3D-реконструкция.** Рельеф, грунт и снег
   не получены из геодезии или спутниковых снимков. По умолчанию включён дневной
   свет для осмотра; кнопка «По времени суток» связывает освещение с часом прогноза.
   Визуализация не изменяет расчёт прогнозов. Без WebGL включается прежняя canvas-карта.
9. **СЭС — реальные станции OSM, прогноз по физике, без факта.** Контуры, названия и мощности — из OSM (у 12 из 26 мощность указана; у остальных на экране «—», не придумываем). Блоки Б1–Б4 — условное деление реального контура на четыре части, мощность блока — доля площади. Прогноз — радиация/облачность/температура Open-Meteo → модель панелей (`live.solar_run`), фактической выработки СЭС нет, поэтому линии «факт» нет. Реестр Минэнерго по СЭС не сопоставлялся.
8. **Крыши — расчёт по физике, не ML.** Выработку даёт отдельный PVGIS-профиль
   выбранного города, тени — по высотам OSM. Для Астаны/Алматы/Шымкента высота известна
   у 55.9%/58.4%/38.3% кандидатов; остальные — допущение по типу. Расчёт покрывает
   выбранный центральный район, не весь город. Полигоны с отверстиями пропущены,
   ширины дорог без тегов оцениваются по классу/полосам. Срезы OSM: Астана 23.09.2026,
   Алматы 28.07.2026, Шымкент 06.05.2026; дата загрузки не равна дате карты.
   Тариф и стоимость установки — допущения, окупаемость не называть фактической.

9. **Исторический прогноз и живой расчёт различаются.** `/forecast/latest` читает
   сохранённые артефакты. Docker теперь содержит ML-стек и обучает модель при сборке;
   `/forecast/run` пересчитывает при `WINDCAST_LIVE=1` — только с токеном и не чаще
   6 раз в минуту на пользователя (`RATE_LIMIT_FORECAST_LIVE`), на репетиции не долбить
   «Обновить». Даты раньше границы обучения финальной модели (31.01.2026) живым
   расчётом не считаются: `/forecast/run` отдаёт сохранённый walk-forward, `/explain`
   и `/predictions/run` — 422. Прогноз текущего момента
   в `/predictions` требует погодного сервиса. Copilot работает с серверным выпуском;
   в mock отвечает расчётным шаблоном, что подписано в UI.

9. **Прогнозы «сейчас» и по станциям без истории требуют интернета у API** (Open-Meteo). Без сети `/predictions/*` отвечают 503 с причиной, экран станции откатывается на демо с плашкой; тестовый период Нурлы (31.01–27.02) работает офлайн из артефактов. У станций кроме Нурлы прогноз — **кривая мощности Нурлы**, не ML: на вопрос «откуда модель для Акмолинской» так и отвечать. Диапазон P10–P90 у них — эвристика (разброс моделей + ошибка по горизонту), не калибровка.

DejaVu Sans (обычный и полужирный) — для кириллицы в PDF-черновиках заявок,
чтобы документ собирался одинаково на Windows и в Linux-контейнере без системных шрифтов.

Источник: копия из дистрибутива matplotlib (`mpl-data/fonts/ttf`).
Лицензия: Bitstream Vera Fonts Copyright + DejaVu changes are in public domain —
свободное использование и распространение, https://dejavu-fonts.github.io/License.html
